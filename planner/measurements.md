# Rooflab measurement checklist

We will keep modeling with labeled estimates. Nothing here needs to be measured before the next rendering update. This is the running list of measurements that would improve the model, starting with the roof.

**Status:** All requests below are open. Previously supplied values are retained; “open” often means that the endpoints or reference surface need clarification, not that the value was discarded. Photo proportions never count as measured dimensions.

## How to record a measurement

Use inches and identify the exact start and end points in a photo or short description. Record the tape reading as closely as you can, plus uncertainty if you know it; do not round a rough reading into false precision. Record driver/passenger side explicitly. For ground-related dimensions, note whether the van is on level ground and whether the bike and normal camping load are aboard.

For roof positions, first mark a front driver-side reference point **O** that can be found again. Measure front-to-back distances parallel to the rails and sideways distances perpendicular to them. For heights, identify the roof or rail surface at the bottom of the tape and the exact surface at the top. Because the roof is curved, heights from different roof spots are not automatically comparable. Keep photos private; the public record needs only relevant measurements and descriptions.

## Keeping this list current

For each new or revised feature, add unresolved dimensions here before treating them as known. Continue with photo estimates until owner measurements or an exact-product source arrive. Close a request only after recording its endpoints, value and evidence in the relevant specs; if references conflict, retain both observations and explain the unresolved difference. Update this checklist and the downloadable shell specs together when a measurement changes model geometry.

This checklist is separate from the editable roof-layout JSON. Personal measurement notes still save locally and travel with roof-layout exports; downloading this file provides the shared request list.
